Запрос GET /posts/1 со статусом 200 OK означает, что сервер успешно обработал обращение и вернул данные первой записи (поста) с идентификатором 1
GET /posts/999999:404 Not Found - Эта строка означает, что запрошенная страница или запись на сервере не найдена. Это стандартный ответ веб-сервера при попытке открыть несуществующий ресурс.
POST /posts: 201 Createdи возвращает в content-type application/json
GET http://github.com: 301,Location: https://github.com, Сервер перенаправляет с http:// на https://, то есть с открытого соединения на шифрованное
Безопасность данных: HTTP отправляет текст без защиты — трафик можно перехватить или изменить. HTTPS шифрует соединение, защищая пароли, карты и личные данные
